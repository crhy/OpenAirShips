# PieSlice224-Full-Airship.blend

Reference copy of the `PieSlice224-Full Airship` mesh as it existed in the
working Blender scene (`AirShip - Open Plan.blend`) before that object was
retired from the live scene.

It is the full craft generated from the February 2024 CAD pie slice: the
eight-fold array of one 45-degree sector, imported into Blender and carrying
the standard Auto Smooth geometry-nodes modifier.

| | |
|---|---|
| Vertices | 595,148 |
| Faces | 1,190,068 |
| Dimensions | 415.263 x 415.263 x 205.209 (object units) |
| Object rotation | 22.632 degrees about Z |
| Object scale | -0.168558, -0.168558, -0.210966 |
| Modifier | Auto Smooth (geometry nodes, edge-angle based) |

Kept so that the Blender model can be checked against the CAD sources in
`CurrentModel/CAD Files` and `CurrentModel/OldFiles`. The current authoritative
CAD sector is `CurrentModel/CAD Files/airship pie slice 125.FCStd`, which is a
later generation than this mesh, so expect differences.
